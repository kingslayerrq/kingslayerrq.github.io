# RQ//BAR — design notes

## Direction

The portfolio is staged as a late-night cyberpunk bar terminal, in the spirit of retro-anime bartending visual novels: a framed viewport, a profile panel, and a dialogue box where the bartender speaks first. Projects are the menu. The fiction is thin on purpose — navigation, headings, and labels stay literal so a recruiter can scan the page in under a minute.

It is a homage to a genre, not a copy of any game. The scene, sprites, palette, copy, and UI are original; no third-party characters, logos, fonts, music, or artwork are used.

## Structure

1. **Stage** — pixel bar scene, profile card (name, role, school, tools, availability), dialogue box.
2. **Label legend** — what *Hand-coded* and *AI-assisted* mean.
3. **Hand-coded** — house specials, gameplay and software.
4. **Built with AI** — clearly separated, amber-tinted window chrome.
5. **About** and **Contact**.

The full menu (`projects.html`) repeats that order with role and provenance filters, then lists smaller work as compact rows.

## Visual system

- **Palette:** deep indigo base (`#0b0817`), violet window chrome, magenta and cyan neon accents, amber reserved for AI-assisted labels and warm light.
- **Type:** Silkscreen for titles and window bars, VT323 for terminal labels and dialogue, IBM Plex Mono for body copy so long case studies stay readable. DotGothic16 covers Japanese glyphs.
- **Windows:** 2px borders, an inner dark inset, and hard offset shadows — no blur, no rounded corners.
- **Sprites:** two 16×16 pixel glasses (cocktail for gameplay, highball for software) recolored through CSS custom properties.
- **Scene:** generated by `scripts/make_scene.py` on a 320×180 grid — rain over a skyline, a neon sign, back-lit shelves, and a counter with a shaker, two drinks, and a terminal.

## Motion and accessibility

Ambient animation is limited to the scene, status lamps, and the dialogue typewriter. The **CRT FX** button turns off scanlines and all animation, is remembered per browser, and defaults to off when the system prefers reduced motion. Without JavaScript the dialogue lines are simply listed and the filters stay hidden. Headings, links, and badges are real text; the scene has a text alternative.

## Provenance labels

Each project declares `build: "hand" | "ai"` in `content/projects.json`. The build refuses to run without it, hand-coded entries always sort first, and tests guard both rules. Mixed cases use a second dashed badge plus a note (for example, a hand-written game with a later AI refactor).
